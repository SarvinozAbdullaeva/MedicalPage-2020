# MedicalPage-2020 landing page

A static one-page website built for a medical service company, created as a university coursework project back in **2020**, built by hand with **HTML, CSS and Bootstrap 4** — no AI tools involved, as none of the current AI coding assistants existed yet at the time.

# Live demo:
https://sarvinozabdullaeva.github.io/MedicalPage-2020/#

## Overview

The page includes:
- A top info bar with logo, services offered, address/hours, and phone number
- A responsive Bootstrap navbar
- A hero/banner section
- A services grid (Bootstrap cards)
- A "Questions" call-to-action section
- A contact section with an embedded Google Map
- A footer with a quick message form

## Tech stack

- HTML5
- CSS3 (custom styles + Bootstrap 4.5.2 grid/components)
- Bootstrap 4.5.2
- Font Awesome 4.7 (icons)
- jQuery 3.5.1 + Popper.js (for Bootstrap's JS components)
